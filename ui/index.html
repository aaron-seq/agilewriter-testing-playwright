Accuracy Scorer

Score a raw QA file against a reference file

Checking config... v

Reference file = what the document should say, written by QA. AgileWriter output = what it actually produced. Scoring compares the two.

Step 1 · Start a reference file from a template

Pulls every placeholder out of a .docx in templates\ and writes a reference file with the expected text left blank, ready for you to fill in.

Step 2 · Fill in the expected text

Type what each placeholder should contain. This is the answer key the AgileWriter output gets scored against.

Step 3 · Check AgileWriter’s document for gaps

Drop the final .docx you downloaded from AgileWriter into generated_documents\. This finds any placeholder it left unreplaced — a document can be marked Final and still have them.

Step 4 · Score the AgileWriter Excel against your reference file.

Fill in expected values

Type what each placeholder should contain. Save, then turn the result into a reference file and score a real AI run against it.
