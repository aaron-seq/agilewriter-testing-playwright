# Repository Overview

## First Mental Model
If you are new:

Run this path mentally:
`Browser UI → Server → Playwright → AgileWriter → Training → Validation → Report`

Then come back and read details.

## What This Component Does NOT Do
* **Node does NOT validate DOCX internal structure:** It only evaluates visible frontend text and overall file generation success.
* **Python does NOT automate browser flows:** It relies on pre-generated documents to perform its tests.
* **No runtime data sharing:** The two ecosystems run entirely independently of each other.

The AgileWriter Automation Suite operates across two distinct ecosystems that validate the AgileWriter platform from different technical angles. 

## Choosing the Right Ecosystem

* **Need to automate browser actions?** → Node
* **Need to inspect generated DOCX structure?** → Python
* **Need to validate AI output quality?** → Node Accuracy Scorer
* **Need to benchmark extraction logic?** → Python

## Operational Relationship
* Shared repository
* Separate execution
* Separate dependencies
* Separate outputs

## 1. The Node.js Frontend Automation Suite

The primary ecosystem in this repository is built on Node.js and Playwright. It is responsible for driving the AgileWriter browser UI exactly as a Medical Writer would. 

**Key Responsibilities:**
* **Health Checks:** Navigating the SharePoint integration, selecting specific source folders, triggering document generation, and tracking the duration and success of background training stages.
* **Accuracy Scoring:** Comparing the final generated DOCX files against expected baseline references to calculate a mathematical accuracy percentage.
* **Orchestration:** Providing a local Express server and web UI (`/ui`) that allows QA engineers to easily select and run these automation scripts.

## 2. The Python Benchmarking Suite

The secondary ecosystem is located entirely within the `benchmarking_automation/` directory. It is responsible for deep, programmatic inspection of the DOCX files generated by AgileWriter, bypassing the browser entirely.

**Key Responsibilities:**
* **Automap Validation:** Programmatically extracting and parsing placeholders, tables, and context from DOCX files to benchmark the backend processing logic.
* **Extraction:** Utilizing direct XML traversal to evaluate how AgileWriter structures its output at the file-format level.
