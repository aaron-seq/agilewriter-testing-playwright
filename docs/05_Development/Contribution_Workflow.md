# Contribution Workflow

> **MANDATORY RULE:**
> Development explains change.
> Architecture explains ownership.
> Execution explains behavior.

## Workflow Purpose

This document defines how repository change becomes accepted change.

The guidance supports the transition of isolated modifications into established repository expectations.

**Confidence**: Observed

## Contribution Philosophy

Change is complete only when behavior remains understandable, documentation remains accurate, and history remains preserved.

Repository change becomes accepted when validation expectations are satisfied and repository understanding remains preserved.

**Confidence**: Observed

## Contribution Lifecycle

Proposal
→ introduce intent

Modification
→ introduce change

Validation
→ confirm outcomes

Documentation
→ preserve understanding

Preservation
→ retain historical context

**Confidence**: Observed

## Contribution Signals

Intent Defined
→ rationale for modification is observable

Boundaries Respected
→ scope of modification is observable

Stability Maintained
→ validation of modification is observable

**Confidence**: Observed

## Validation Gate

Proportional Validation
→ confirm local stability for isolated changes

Broad Validation
→ confirm regression stability for shared changes

Documentation Validation
→ confirm canonical guidance reflects accepted change

**Confidence**: Observed

## Documentation Expectations

Update Canonical Guidance
→ reflect new operational state

Verify Interpretability
→ ensure the modification can be understood without execution

**Confidence**: Observed

## Historical Preservation Expectations

Preserve Prior Context
→ retain historical understanding

Log Rationale
→ document why change was introduced

**Confidence**: Observed

## Contribution Boundaries

Supported Contribution
→ changes fulfilling validation and preservation expectations

Escalation Required
→ changes challenging established boundaries

Unsupported Contribution
→ undocumented or unpreserved repository change

**Confidence**: Observed

## Completion Criteria

Contribution complete
→ validation performed

Contribution understood
→ documentation updated

Contribution preserved
→ historical context retained

**Confidence**: Observed
